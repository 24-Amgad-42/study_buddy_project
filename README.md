# منظم المهام الدراسي 📚
## Student Study Buddy Project

---

## نظرة عامة على المشروع

**منظم المهام الدراسي** هو موقع ويب تفاعلي مصمم خصيصاً لمساعدة الطلاب على تنظيم مهامهم الدراسية وجدولة جلسات المذاكرة وتتبع تقدمهم بكل سهولة وفعالية. تم تطوير هذا المشروع كجزء من متطلبات مقرر **أساسيات تطوير الويب 1** (Web Development Fundamentals).

---

## المميزات الرئيسية ✨

| المميزة | الوصف |
|--------|--------|
| **تصميم متجاوب** | يعمل بشكل مثالي على جميع الأجهزة (هواتف ذكية، أجهزة لوحية، حواسيب) |
| **إدارة المهام** | إمكانية إضافة مهام جديدة، عرضها، وحذفها بسهولة |
| **تخزين محلي** | استخدام `localStorage` لحفظ البيانات محلياً في المتصفح |
| **الوضع الليلي** | ميزة تبديل المظهر بين الفاتح والداكن للراحة البصرية |
| **واجهة سهلة الاستخدام** | تصميم بسيط وواضح يسهل على المستخدمين التنقل والاستخدام |
| **التحقق من البيانات** | التحقق من صحة المدخلات قبل حفظ المهام |

---

## التقنيات المستخدمة 🛠️

تم بناء هذا المشروع باستخدام التقنيات الأساسية لتطوير الويب:

- **HTML5**: لإنشاء هيكل صفحات الويب بشكل دلالي وصحيح
- **CSS3**: لتنسيق الصفحات وجعلها متجاوبة مع استخدام Flexbox و Media Queries
- **JavaScript (Vanilla)**: لإضافة التفاعلية والديناميكية دون الاعتماد على مكتبات خارجية
- **localStorage API**: لتخزين البيانات محلياً في المتصفح

## الصفحات الرئيسية 📄

### 1. الصفحة الرئيسية (index.html)
تعرض مقدمة عن الموقع ومزاياه، مع أزرار سريعة للانتقال إلى صفحات أخرى مثل إضافة مهمة جديدة أو عرض المهام الموجودة.

### 2. صفحة المهام (tasks.html)
تعرض قائمة بجميع المهام المحفوظة مع إمكانية حذف أي مهمة. إذا لم تكن هناك مهام، يتم عرض رسالة توضيحية.

### 3. صفحة إضافة مهمة (add_task.html)
تحتوي على نموذج لإضافة مهام جديدة يتضمن:
- حقل عنوان المهمة (مطلوب)
- حقل الوصف (اختياري)
- حقل تاريخ التسليم (مطلوب)

### 4. صفحة حول المشروع (about.html)
تعرض معلومات عن المشروع وأهدافه وفريق العمل مع جدول يوضح أسماء الفريق والأرقام الجامعية والأدوار.

## كيفية الاستخدام 🚀

### التثبيت المحلي:

1. **استنساخ المستودع**:
   ```bash
   git clone https://github.com/24-Amgad-42/study_buddy_project.git
   cd study_buddy_project
   ```

2. **فتح الموقع**:
   - افتح ملف `index.html` مباشرة في متصفحك
   - أو استخدم خادم محلي (مثل Live Server في VS Code)

### الاستخدام الأساسي:

1. **إضافة مهمة جديدة**:
   - انقر على "إضافة مهمة" من القائمة العلوية
   - أدخل عنوان المهمة وتاريخ التسليم
   - انقر على "حفظ المهمة"

2. **عرض المهام**:
   - انقر على "المهام" من القائمة العلوية
   - ستظهر جميع المهام المحفوظة

3. **حذف مهمة**:
   - انقر على زر "حذف" بجانب المهمة
   - أكد الحذف عند الطلب

4. **تبديل المظهر**:
   - انقر على زر "تبديل الوضع" في الزاوية العلوية اليمنى
   - سيتم التبديل بين الوضع الفاتح والداكن

## ملاحظات تقنية 💡

### localStorage:
تستخدم التطبيق `localStorage` لحفظ المهام محلياً. هذا يعني أن البيانات ستبقى في المتصفح حتى يتم حذفها يدوياً.

### الأمان:
هذا المشروع مخصص للتعليم ولا يتضمن ميزات أمان متقدمة. لا يتم إرسال البيانات إلى خادم بعيد.

### التوافقية:
الموقع يعمل على جميع المتصفحات الحديثة التي تدعم HTML5 و CSS3 و JavaScript ES6.
